# Hotel Booking Management Portal
React + React Router + JSON Server.

## Run
```
npm install
npm run server   # terminal 1 -> http://localhost:3000
npm run dev      # terminal 2 -> http://localhost:5173
```
Features: Room CRUD, Customer CRUD, room search + type filter, availability-based booking, cancellation, booking details, total amount calculation, dashboard.

## Extra features
Dashboard (occupancy, revenue by type, upcoming check-ins), room cards with live Vacant/Occupied status, search/filter/sort, guest-capacity aware availability, special requests, customer stay history and spend, confirm dialogs, toast messages, printable invoice, server-down error handling.
